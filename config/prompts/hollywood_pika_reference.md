# Pika 能力边界（VIDEO-RCA 实测，docs/video_rca/RCA_r1.md）

P1. 4 帧一顿是 Pika 基底本身的毛病，写法改不掉。系统会在后期去抖。不要指望靠提示词消除顿挫；动作越快越明显，优先写连续、匀速的动作。（高）——RCA_r1.md §1 表 C9

P2. 外套会在动作中途消失又“穿回”（ep01-S3“站起 + 整理外套”第 63–110 帧外套消失，复现 1/1）。避免在一镜里写“站起同时整理 / 拉 / 脱外套”这类大动作 + 服装交互；需要换装、披衣的，拆成不同镜头、用首帧交代。（高）——RCA_r1.md §1 表 C6、C8

P3. 景别多数由首帧决定，视频还会往远退（视频比首帧再远 ≥1 档 11/55）。想要近景 / 特写，首帧提示词必须就是那个景别；不要指望视频里“推近”补救。（高）——RCA_r1.md §1 表 C16

P4. 近景 / 中景的描述里不要写画面外的下半身造型（带鞋 / 高跟 / 腿的近景、中景 62/111 退档，不带的 0/7）。景别看不到的部位别写进这一镜。（中）——RCA_r1.md §1 表 C16

P5. 视线落点写画内的人或物；画外的写方向（toward frame-left / down toward the desk edge），不写画外名词。（低–中）——knowledge/inbox/2026-11-01_video_rca_writer.yaml K-WRT-701；RCA_r1.md §1 表 C4

P6. 首帧看镜头，视频基本也看镜头（49/54）；“不看镜头”要落在首帧提示词里（看对方 / 看画内物件），视频段的视线写法只是辅助。（高）——RCA_r1.md §1 表 C1、§6

P7. 首帧是正面对称站姿，Pika 就只做微动（站桩）。首帧写成“正在做某个动作”的瞬间，不写站好亮相。（中）——RCA_r1.md §1 表 C3

P8. 多人镜第二个人写了就演，没写就呆。每个在画的人都写一句具体的视线或小动作。（低–中）——RCA_r1.md §1 表 C4

P9. 脸红类描述（flush / blush / redden / 脸红 / 涨红）= 这一镜被挂起不出片（泛红防护）。情绪用动作和视线表达。（高）——RCA_r1.md §1 表 C13；config/pipeline/video_policy.json reason_overlay.flush_risk

P10. 大动作镜头会变软（大动作镜中段清晰度比值 0.469）。需要清晰脸部的镜头，动作幅度写小。（中）——RCA_r1.md §1 表 C12

P11. 单镜最短可生成 4.46 秒（107 帧），**时长** 4–15 秒整数；2–3 秒的刀只能在剪辑里裁。——config_audit.md（ns_schema lint RL-G3）

P12. **K-WRT-702（规则原文，knowledge/inbox/2026-11-01_video_rca_writer.yaml；RSI r7 收编为正式 lint）**：分拍里不写“对身上正穿着的衣服做动作”（整理 / 抚平 / 拉 / 收紧 / 掀起外套、衣摆、衣领）——视频模型会演成脱下再穿上。
写作方原文：“分拍动作不要写对身上正穿着的衣服的整理动作（抚平外套下摆、拉衣角、收紧衣领等）：视频模型会把外套先脱掉再穿回。想表达整理 / 镇定，写不碰衣服的动作，例如手放回身侧、深吸一口气、肩膀放松。”确需穿脱衣物的情节单独成镜，并在首帧 / 尾帧里把穿脱前后都画出来。
证据：ep01-S3“she smooths the hem of her blazer”Pika 换 seed / 加服装保持句 / PDD 6/6 外套 3.3–3.9 秒消失再穿回；只把这一拍换成“she lets her hands settle at her sides”2/2 全程穿着；保留动作只补“the blazer staying on her shoulders”2/2 仍消失（写法补救无效）。合计：带对衣服动作 8/8 消失，去掉 0/2。（高）——data/ab/video_rca/r4_pika、r8_outfit_action、r9_outfit_keep；docs/video_rca/RCA_r2.md
评审：任何一镜分拍写了对身上衣服的整理动作，“运动是否符合 Pika / LoRA 能力”一项不能给 4 分以上。

## VIDEO-RCA r2 新结论（docs/video_rca/RCA_r2.md，11-01；r3 补，总调度转项目方 22:1x）

P13. **Pika 不会自己转头看镜头**：首帧两人互看时，Pika 第 0 / 48 / 96 / 150 / 188 帧 × 2 张脸 = 20 个样本，0 个看镜头（RCA_r2 §1 Q①）。所以“不看镜头”只要首帧（img）里视线落在画内的人 / 物上就够了；视频段不要写“转头看向镜头 / 回头”。（高）

P14. **对衣服的动作 = 外套消失**：见 P12（K-WRT-702，正式 lint QW-W11）。带对身上衣服动作 8/8 消失、去掉 0/2。（高）

P15. **慢动作镜是真 4 帧一顿，系统已有去抖**（tools/dejudder.py，门槛 J4 > 1.2）：写慢、匀速的动作即可，不必为了躲顿挫把动作写快或写大。（高）——RCA_r2 §3 K-REV-705

P16. **景别主要由首帧决定**（同 P3）：要特写就把 img 写成特写；视频里推近幅度写“小”，不靠推拉换景别。（高）

## 把剧情里的大动作写成 Pika 做得出的镜头（格式做法，不改剧情）

- **一镜只放一个主动作**：站起 / 走开 / 递东西 / 披衣各算一个；一镜里出现两个以上就拆成相邻两镜（衔接写 接力 或 同场换机位），总镜数按系统给的每镜 6 秒重算。
- **剧情事实里有“披外套 / 脱外套 / 换衣”**：拆成两镜——前一镜只写手拿着衣服靠近、停在肩上方（衣服还没碰到身上）；后一镜的 img（首帧）里衣服已经在肩上，分拍只写不碰衣服的小动作（呼吸、视线、手指）。不在一镜里写“披上 / 抖开 / 拉好”的过程。
- **站起 / 转身走开**：写成镜尾的起势（重心前移、手撑桌沿），下一镜首帧已经站着 / 背影；不在一镜里写“站起 + 走开”。
- **运镜**：一镜一种运镜，幅度小；Arc（环绕）不和大动作叠用。
- **情绪**：用视线落点、呼吸、手指、停顿表达；不写脸红类词（P9）。
