# 短剧镜头提示词评审（独立评审调用）

## 一、量表原文（项目方 11-01，照抄）

- 第三步：RSI 迭代（生成 → 打分 → 只改不及格项 → 再打分）。量表 10 项，每项 1–5 分：5 秒钩子、冲突是否成立、转折密度、人物目标 / 阻碍 / 赌注是否清楚、是否 show 而非 tell、画面 specificity、运动是否符合 Pika / LoRA 能力、人物一致性、台词潜台词、结尾钩子。每轮只改低于 4 分的项，4 分以上原样保留；最多 3 轮；全部 ≥4 分或连续两轮无提升即停；保留得分最高的版本，不默认用最后一版。
- 红线：不改给定的剧情事实和人物设定，缺信息就按已有设定写成具体内容（项目方 11-02 21:3x）；遵守当地法律和平台规则。
- 系统：视频 Pika（LoRA 基于 MiniMax H3），图片 2.1 图像模型，竖屏短剧，每集 60–120 秒。

每项满足几条就是几分（0 条记 1 分），5 条全满足 = 5 分。逐条核对，写出每条满足 / 不满足；不满足的写镜号和原因。

### hook5s（5 秒钩子）
1. 镜1 的时长字段为 4–6 秒整数，且分拍字段把 0–5 秒切成至少两段、每段写明具体动作或台词（只写一段或写“0–6 秒”整段即不满足）。
2. 镜1 的 img（首帧）字段写明“具体人物 + 正在做的动作瞬间”（如“她手指停在半开的抽屉上”），不是空镜、不是“站好亮相”式静态站姿（P7）。
3. 镜1 分拍 0–5 秒内出现第一句台词或第一个可指认动作，评审遮住镜2 及以后全部镜头、只看镜1，仍能用一句“谁、遇到什么事”复述出来。
4. 镜1 的景别字段为近景或中景（首帧即景别，P3/P16），且该镜 img 里没有写画面外的下半身造型（鞋 / 高跟 / 腿，P4）。
5. 镜1 全文不含脸红类词（flush / blush / redden / 脸红 / 涨红，P9）、不含对身上正穿衣服的整理动作（整理 / 抚平 / 拉 / 收紧 / 掀起外套衣摆衣领，P12），钩子由视线落点、呼吸、手指或台词承载。

### conflict（冲突是否成立）
1. 剧本中能逐字指出两个具名人物（或一个具名人物与一个具名阻碍方），且这两方在至少一镜里同框，或通过该镜台词字段直接对上话。
2. 至少一镜的台词或分拍字段写明“一方要 X、另一方要非 X”的相反诉求，评审能引用该镜镜号与该句原文。
3. 冲突在镜1–镜3（前 18 秒内）已经显形：镜1–镜3 中至少一镜的分拍或台词字段出现对抗性动作或对抗性台词，不是等到中段才出现。
4. 冲突有可见代价：至少一镜的分拍字段里写了一个具体损失或威胁（物件被拿走、位置被占、话说出口收不回），且该事件写在分拍字段而非旁白字段。
5. 把全片旁白 / 字幕字段全部删掉后，冲突仍能从台词字段与分拍动作字段读出（删掉后读不出即不满足）。

### turns（转折密度）
1. 全片镜号连续无缺，镜数在 10–20 之间（60–120 秒 ÷ 每镜约 6 秒），超出区间即不满足。
2. 至少每 3 镜（约 18 秒）出现一次“预期被推翻”的具体事件，且该事件写在某一镜的分拍字段里；评审能逐条列出，条数 ≥ 总镜数 ÷ 3 向下取整。
3. 每次转折都有前置铺垫：转折镜之前至少一镜的分拍或 img 字段写了对应信息（物件 / 台词 / 视线），评审能写出“铺垫镜号 → 转折镜号”的对应关系。
4. 转折用到的每个人物与道具，其首现镜号都小于转折镜号（不靠转折镜里新冒出来的元素制造反转）。
5. 最后一镜（镜号 = 总镜数）本身构成一次转折或新信息，且与前面任何一镜的分拍事件不重复（评审逐镜比对，重复即不满足）。

### gos（人物目标 / 阻碍 / 赌注）
1. 主角的目标能落到某一镜的台词字段或分拍字段里，评审能引用该镜镜号与原文（只能概括成“她想改变命运”这类无法指认的句子即不满足）。
2. 阻碍方在至少一镜里有具体的阻挡动作或阻挡台词，写在分拍或台词字段（只写“气氛压抑”“众人反对”即不满足）。
3. 赌注写明“失败会失去什么”的具体物件 / 关系 / 身份，且该物件在至少一镜的 img 或分拍字段里以具体名词出现过。
4. 目标、阻碍、赌注三者在同一镜或相邻两镜内被同时看到，评审能指出该镜镜号（分散在片头片尾、中间无交集即不满足）。
5. 把全片旁白字段删掉后，目标 / 阻碍 / 赌注仍能从台词与分拍动作读出。

### show（show 而非 tell）
1. 逐条核对每一条 🎙 内心独白：其所在镜的分拍字段里都有一个与之对应的可见动作或视线落点（有独白无动作即该条不满足）；独白条数与先后顺序与原稿一致，不增删、不调序。
2. 每个情绪点（愤怒 / 委屈 / 心动 / 害怕）在分拍字段里都有一个不碰衣服的具体身体动作或视线落点，评审能逐条写出“情绪 → 镜号 → 动作”对应表。
3. 台词字段与旁白字段中不出现“她很生气 / 他很震惊 / 我很难过”这类形容词直陈句（逐字检索情绪形容词，出现即不满足）。
4. 关键信息（身份、关系、秘密）至少有一次是用画面物件或动作传达，而不是由台词直接说破；评审能指出该镜镜号与该物件 / 动作。
5. 情绪表达全文不含脸红类词（flush / blush / redden / 脸红 / 涨红，P9），也不含对身上正穿衣服的整理动作（P12）。

### specificity（画面 specificity）
1. 逐镜核对 img 字段，四项齐全：景别 + 人物（姓名或人物卡编号）+ 具体动作瞬间 + 视线落点；任一镜缺任一项即不满足。
2. 逐镜核对分拍字段，必须按秒切段（如 0–2 / 2–4 / 4–6），每段只写一个主动作；某段出现两个以上主动作即不满足。
3. 场景与道具写可指认的具体名词；全文不出现“一些东西 / 之类的 / 各种”这类模糊词（逐字检索，出现即不满足）。
4. 视线落点写画内的人或物，或写方向（toward frame-left / down toward the desk edge）；写画外名词（如 toward her mother，而母亲不在画内）即不满足（P5）。
5. 近景 / 中景镜的 img 字段不写画面外的下半身造型（鞋 / 高跟 / 腿）；出现即该镜不满足（P4）。

### pika（运动符合 Pika / LoRA 能力）
1. 逐镜核对分拍字段，每镜只出现一个主动作（站起 / 走开 / 递东西 / 披衣各算一个）；任一镜出现两个以上主动作即不满足（P2、P12 格式做法）。
2. 全文没有任何一镜的分拍写“对身上正穿着的衣服做动作”（整理 / 抚平 / 拉 / 收紧 / 掀起外套、衣摆、衣领）；出现即本项不得 4 分以上（P12 / K-WRT-702）。
3. 景别与运镜：要近景 / 特写时 img 字段写的就是该景别，视频段不写“推近”补救；一镜一种运镜、幅度小，Arc（环绕）不与大动作叠用（P3 / P16）。
4. 视线：img 字段写明看不看镜头（不看镜头就写看对方或看画内物件），视频段不写“转头看向镜头 / 回头”（P6 / P13）；多人镜里每个在画的人都写了一句具体的视线或小动作（P8）。
5. 全文不含脸红类词（flush / blush / redden / 脸红 / 涨红，P9）；动作写连续、匀速、幅度小（P1 / P10 / P15）；每镜时长字段为 4–15 秒整数（P11）；首帧写“正在做某个动作的瞬间”，不写站好亮相（P7）。

### consistency（人物一致性）
1. 每一镜出现的每个人物都标注人物卡编号或姓名，且该镜 img 的外貌行与人物卡“外貌”行逐字一致（发色 / 发型 / 瞳色等）；逐字比对，有一处不同即不满足。
2. 该镜 img 的服装描述与人物卡“服装”行同一套（颜色 + 款式 + 件数逐项对上），不出现人物卡里没有的衣物件；多一件或少一件即不满足。
3. 该镜 img 的造型行（妆 / 配饰 / 随身道具）与人物卡“造型”行逐字一致，不新增人物卡未写的配饰。
4. 换装镜单独成镜：该镜 img 或上一镜尾帧写明换装前 / 换装后的完整穿着，分拍里不写“披上 / 抖开 / 拉好”的穿脱过程（P12）；一镜内写穿脱过程即不满足。
5. 逐对核对相邻两镜：同一人物的服装 / 发型若无交代地变化即不满足；变化时中间必须有一镜写明换装（评审能指出该换装镜号）。

### subtext（台词潜台词）
1. 逐句核对台词字段，每句都能写出“字面意思”与“真实意图”两层；任一句写不出两层即不满足。
2. 至少一镜的台词与同镜分拍动作相反或错位（如台词说“没事”、分拍写手指在抖），评审能指出该镜镜号与该句原文。
3. 台词字段中不出现把意图直接说破的句子（“我其实是想……”“我恨你因为……”）；逐字检索，出现即不满足。
4. 每镜台词 ≤2 句，且每句都有对应的反应镜：下一镜分拍字段里写了听者的具体反应动作或视线落点（缺反应镜即该句不满足）。
5. 潜台词由视线落点、停顿、呼吸、手指等不碰衣服的动作承载，全文不含脸红类词（P9）、不含对身上正穿衣服的整理动作（P12）。

### endhook（结尾钩子）
1. 最后一镜（镜号 = 总镜数）的分拍字段在最后 2 秒内写了一个新信息（原稿已有的人物入画 / 原稿已有的物件出现 / 一句新台词），并标明具体秒段；只写“气氛凝固”即不满足。
2. 该新信息在最后一镜之前从未以“被看清 / 被说出 / 被指认”的方式呈现过：逐镜检索，其揭示镜号必须等于最后一镜镜号（此前只可作背景或未被注意地出现，评审能指出此前出现镜号与最后一镜揭示方式的差别）。
3. 最后一镜时长字段为 4–6 秒整数，且新信息落在该镜最后 2 秒内，不靠下一集旁白或字幕补完。
4. 结尾钩子指向一个未解决的具体问题，评审能用一句“谁要做什么 / 谁会怎样”复述；且该问题在前面至少一镜里有铺垫（该镜提到相关物件或台词，评审能指出镜号）。
5. 最后一镜不含脸红类词（P9）、不含对身上正穿衣服的整理动作（P12），且 img 字段写的就是目标景别（不靠视频推近，P3 / P16）。

## 四、清单打分的输出格式（r5，系统写，只讲格式；取代 §二 的 score 写法）

只输出一个 ```json：每项列出满足的条件编号 `met` 和不满足的条件 `unmet`（每条写编号、镜号、原因），分数由系统按 met 条数计算，你不用写 score。

```json
{"checks": {"hook5s": {"met": [1, 2, 4], "unmet": [{"id": 3, "shots": [1], "why": "镜1 0–5 秒内……"}, {"id": 5, "shots": [1], "why": "……"}]},
            "conflict": {"met": [1, 2, 3, 4, 5], "unmet": []}, "turns": {...}, "gos": {...}, "show": {...}, "specificity": {...},
            "pika": {...}, "consistency": {...}, "subtext": {...}, "endhook": {...}},
 "note": "一句总评"}
```

met 与 unmet 的编号合起来必须正好是 1–5，每条只出现一次。

## 五、刁钻评审（第三个评审的附加要求，系统写）

你是第三个、专门找扣分点的评审：对每一条条件都先假设它“不满足”，只有在镜头块里能逐字指出满足它的原文（镜号 + 字段 + 原文片段）时才算满足；
拿不准的一律记不满足，并写清楚还缺什么。输出格式同 §四。

## 六、带证据的逐条判定（r5 修尺子，总调度 11-02 01:4x；取代 §四 的输出格式）

对 §三 清单的每一条（10 项 × 5 条 = 50 条）逐条判定。只输出一个 ```json：

规则：met=true 必须给 evidence，且 evidence 必须是镜头块里能逐字找到的原文；“全文不含 X”这类条件，evidence 写“全文检索无 X”。没有证据就写 met=false。

## 七、v3 判断条目（总调度 11-02，来自 JUDGE 第二季共性弱点；和 §三 的 50 分分开记）

在 §六 的 JSON 里再加一个 "v3" 键，每条格式同 §六（met + 逐字 evidence + why）：
{"v3": [{"id": "stakes", ...}, {"id": "opposition", ...}, {"id": "subtext_contrast", ...}, {"id": "open5s", ...}]}
- stakes（赌注）：画面或台词里看得见“失败会失去什么”（具体的人、物、位置、关系），不是抽象情绪。
- opposition（阻碍方）：有一方诉求和主角相反，并在本集当面施压或拒绝；全集只有顺从、问候、配合 = 不满足。
- subtext_contrast（潜台词反差）：至少一处台词和同一镜的动作相反（嘴上说没事，手在攥紧），台词不直说意图。
- open5s（开场 5 秒）：镜 1 交代“谁遇到了什么事”（人物在画 + 一件正在发生的事），不是空镜或氛围。
另外在 JSON 顶层写 "judge_id"：你自己的评审 agent 名或 id（σ 检验要求 3 份来自 3 个不同评审）。

## 八、判定口径细化（总调度 11-02：第二季 v2 / v3 盲评中 σ>1 的组逐条对出三家分歧后写细；通过线不变）

依据：data/rsi/judge_blind/_keys/s2_v2v3_r1/DISAGREE.json（v2 ep02、v3 ep02、v3 ep03 三组，分歧最多的条目按次数：specificity#1 3 次、subtext#1 3 次、gos#1 / #4 / #5 各 2 次、pika#5 2 次）。
- specificity#1“具体动作瞬间”：img 里有一个正在发生的动作动词（拿起 / 推开 / 按下 / 递 / 攥紧 / 撑着…起身）才算；人物和物件有接触的姿态（扶着、撑着、倚着、靠着）也算，因为这是 K-WRT-H15 要求的写法。只有表情或静止状态（站着、侧脸、嘴唇张开、眼睑垂下）、没有动作或接触的，不算。逐镜判，任一镜不满足即整条不满足。
- subtext#1“每句两层”：两层可以都在台词里，也可以字面在台词里、真实意图在同一镜的动作或视线里（例：“会疼。”同镜手指在攥紧针盘边 = 两层）。台词直说、同一镜动作也只是在重复字面（例：“不加。”同镜只写摇头）= 一层。短句不因为短就判不满足，要看同镜有没有第二层。
- gos#1“主角目标”：主角 = 本集人物卡第一位（按本剧 P1 人物表，不写死人名）。目标要落在台词或分拍里，写成她想得到、想阻止或要决定的具体事情（例：“这次我定”“人选我来写”）。只是陈述现状（“我自己写的”）不算目标。
- gos#4 / gos#5：赌注按 §七 stakes 的口径判。stakes 不满足时，gos#4 和 gos#5 一律不满足，不要一家判满足、另一家判不满足。
- pika#5：只判两件事：①全文没有脸红类词；②动作写成连续、匀速、小幅度。“首帧是不是动作瞬间”归 specificity#1 判，这里不重复扣分。
- §七 stakes：要能指出镜号和原文，写清“失去的东西”是具体的人、物、位置或关系，并且台词或画面交代了失去它的条件（例：“说不出来，这张卡留下”）。只有气氛紧张、没写会失去什么的，不算。
