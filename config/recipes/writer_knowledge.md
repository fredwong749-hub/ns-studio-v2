## 镜头字段
- 接力 / 同场换机位镜头必写 **下镜**（结尾仍在进行、留给下一镜的动作）；下一镜 H3 第一句用 already / still / mid- 接上同一个动作。 [K-WRT-I01]
- motion 第一句写一种运镜加幅度（例：camera push in 小幅推近），不写“缓慢”这类速度词；不用拉远、环绕、晃动——Pika 本来就会往远退，环绕和大动作叠在一起会变形。 [K-WRT-801]
- 衔接写“接力”时，后面写清接的是什么：动作｜具体动作、视线｜看向哪、环境｜什么声音或光、位置｜站位；剪辑按它决定动作匹配切还是视线匹配切。 [K-WRT-802]
- 镜头运动字段只写运镜词表里的名字，每镜一种，幅度写“小幅”，不写速度词。当前可用：固定镜头（对白、克制、停顿、大动作；特写/近景/中近景/中景/中全景/全景）；推近（情绪推高、发现、高点；近景/中近景/中景/中全景）。词表里其余（拉远、摇镜（水平）、上摇、横移、升镜、变焦推近、环绕、焦点转移、慢镜头、前景遮挡、甩镜、上升环绕、变速推近、主观视角、手持晃动、旋转）Pika 上没验证通过，写了会被编译层改成固定镜头；复合运镜按词表拆成两镜。 [K-WRT-804]
- 每镜镜头块按七段写，每段一句、顺序固定：①机位与景别（谁在画面、角度、景别档）②镜头参数（焦段 / 光圈 / 景深，可省）③构图（前景 / 中景 / 后景放什么、人物在哪个三分点、留白方向、视线方向）④灯光（见灯光规则）⑤运镜（运镜词表名 + 起幅 → 落幅 + 小幅）⑥表演节拍（0–2 / 2–4 / 4–6 秒各写动作、微表情、视线落点、呼吸、手部细节，视线落在画面里的人或物上）⑦声音。不堆形容词，一个名词前最多两个形容词。 [K-WRT-805]
- 每镜写【灯光】：用灯光词表里的方案名（如“深夜办公室·台灯”），或写三要素——动机光源（写成“动机光源=<光源>（方位）”；光源是画面里看得见的东西——窗、台灯、门口天光、柜台油灯、烛台都行，只要它写在本镜或本场的场景描述 / 道具里，或是灯光词表里的词）、布光比（2:1 柔和到 8:1 戏剧）、色温（K 值或暖 / 冷）；可加人物适配（发色高光、皮肤质感、美甲反光点）。人物和背景用同一套光。 [K-WRT-806]
- img 句只写这个景别看得见的东西（特写 / 近景不写鞋、跟、裙摆、地面上的鞋尖）；用肯定句写要的样子，不写“不… / 无… / 不是…”； 服装逐件写名称 + 颜色 + 材质（例：及膝深灰羊毛铅笔裙）；两人同框时“两人都露脸”和“一人局部 / 虚化 / 背影”二选一，不混写。 [K-WRT-Q29]
- 写手部局部 / 大特写时，img 里不要同时写肩头、颈、锁骨或胸口；模型会把这种镜画成带肩颈甚至带脸的近景。只要手，就把肩颈的动作放到下一镜；肩颈也要入画，就把景别写成“近景（手与肩颈）”。 [K-WRT-V10]
- 画面描述里的脸红 / 绯红类词，在当前首帧与视频模型上会稳定渲染成脸颊大片红斑且随时间加重，会触发泛红质检；如需写，请在 img 与 H3 正文保持一致并接受质检复看。 [K-WRT-R01]
- **衔接** 行的“承：”和 **下镜** 行写明接力类型（动作 / 视线 / 环境 / 无）和具体接力元素（哪个动作、看向什么、哪件环境物），例：承：视线｜看向门口。 [K-WRT-R06]
- 人物在画的特写 / 近景 / 中景，img 的光线写成“光源 + 方向或落点”（例：台灯暖光从右侧逆光勾出发丝与颈线；屏幕冷白光从正面打在脸上）； 只写“暖黄居家灯光 / 光线柔和”这类没有方向的光，出图会落成均匀平光，脸更像磨皮。 [K-WRT-X05]
- 一镜只拍一个连续镜头（H3 里只有一个 [Shot 1]）；镜内要从特写到近景，写成推 / 拉 / 摇的连续运镜；要换机位或换景别跳档，就拆成下一镜。 [K-WRT-101]
- 不在一镜的 H3 里写 [Shot 2] / cuts to；正反打、切景别都拆成相邻两镜（剪辑时切）。 [K-WRT-102]
- 每镜都写清 景别（词表）+ 机位（低机位 / 平视 / 俯拍 / 过肩 / 主观视角 / 侧面）+ 一个运镜；**镜头运动** 行写 官方运镜词｜幅度=小/中/大｜速度=慢/正常/快，与 H3 运镜句一致。 [K-WRT-103]
- 两人对话优先写 过肩 / 侧 3/4 / 双人中景，不写两张正脸对镜头；正反打的相邻镜里两人在画面左右的位置不变（**人物** 行左右逐镜一致），越轴就在 **衔接** 里写“越轴”或 HARD CUT 并写清原因。 [K-WRT-104]
- 同一场戏里景别随情绪递进（建立 → 互动 → 高点特写），特写 / 大特写留给反应高点和关键物件；相邻同景别的镜头连续不超过两镜。 [K-WRT-105]
- 竖屏构图：人物至少中景、脸占足画面，主体放在上 1/3，人物视线方向留出空间；不在 H3 里写 9:16 或分辨率（工作流设定）。 [K-WRT-107]
- 每镜 **下镜** 行写转场：动作匹配切 / 视线匹配切 / 硬切 / 叠化 N 秒 / 声音先行 N 秒，外加结尾仍在进行的动作；H3 里不写 dissolve、fade（单镜生成，转场由剪辑完成）。 [K-EDT-101]
- 同场相邻镜用动作匹配（下一镜从上一镜动作中段进）或视线匹配（上一镜看向哪，下一镜就是哪）；换场用声音先行 0.3–0.5 秒；时间过渡才用叠化 0.3–0.5 秒。 [K-EDT-102]
- img 只写这个景别下画面里看得见的造型部件（特写 / 近景不写裙长、鞋、腿；中景不写鞋）；系统会按景别删掉看不见的部件并在首句写景别构图。 [K-REN-101]
- “人物”行和画面要对得上：正文写到谁的眼睛 / 视线 / 嘴唇 / 表情 / 脸，谁就写“在画”；“局部｜<部位>”只用于真的只露手、背影或下半身的人。特写、近景、中近景里只有一个人且写了视线，就一定是“在画”。 [K-WRT-705]
- 灯光只写有动机的主光：一个画面里看得见的光源 + 方向 + 光比（≤3:1），再写负补光（暗侧用黑旗吸光，不补亮）和背景比人物低 1–2 档的亮度。禁止“正面高亮 / 把影子打平 / 白幕反射补脸 / 平光 / 均匀布光”这类平光句——它们会让画面发白、没有立体感。场景表里的光线列同样不许写。 [K-WRT-807]
- 两人以上在画时，【构图】必须写前 / 中 / 后三层：“前景=谁的什么部位略在焦外｜中景=谁在焦点上｜背景=谁或什么陈设”，cast 里的 depth（前 / 中 / 后）要和它一致。在焦点上的主体脸高不得低于本镜景别档位的下限（错落写过头会把中景拍成中全景，小脸不过身份检查）。 [K-WRT-808]
- 同一场里连续的镜头，不许连续两镜都是“正面 / 侧面平视 + 全身或中景一字排开”：至少一镜换机位（侧 45° / 过肩 / 俯仰）或换景别（中近景 / 近景）。 [K-WRT-809]
- 写分镜前先在集头写“本集镜头规划”：每一场一行——轴线（谁在画面左、谁在右、各自看向哪一侧）、焦段档位（每个景别档用 lenses.yaml 的哪个 id）、coverage（先一镜最宽的主镜头把所有人放进画面，再过肩，再单人；景别随情绪由宽到紧）。之后每一镜的机位、景别、焦段都从这段规划里取，不临时发明。 [K-WRT-810]
- 一场戏开拍前定一条轴线（两个人之间的连线），所有机位都在轴线同一侧：同一场里甲永远在画面左、乙永远在画面右；【构图】的“视线方向=甲向右看乙”必须和人物行里乙在右一致。要越轴只用两种办法——先插一镜机位正压在轴线上的中性镜，或在一个镜头里让机位可见地跨过去——并在【衔接】写明“越轴”。 [K-WRT-811]
- 每镜写一行【镜头】，只写 config/director/lenses.yaml 的 id，并按景别取档（L-192）：建立镜头 leica_cine_28_t28 或 leica_cine_35_t4（24–35mm T2.8–4，一场最多一个）；双人 / 中景 arri_cine_50_t2（50mm T2）；过肩 / 单人近景 arri_cine_65_t14 或 arri_cine_85_t14（65–85mm T1.4）；特写 arri_cine_85_t14 或 leica_cine_135_t12（85–135mm T1.2–1.4）；插入镜头 leica_cine_100_macro_t2（100mm 微距 T2）。同一场里同一个景别档永远是同一支镜头，正反打的两镜用同一支镜头。也可以直接在【光学】行写 焦段mm｜T 值｜高度=…（K-WRT-816）。 [K-WRT-812]
- 每镜【运镜】写四项：词表里 enabled 的运镜名｜幅度｜起幅 → 落幅｜动机=这镜为什么动（情绪推高、发现、说话人开口、跟随走动、登场爆点）；motion 开头和【镜头运动】要是同一种运镜。固定镜头整集不超过 20%，而且要写清为什么不动（人物出画、重复比较、等对方回答）。只用 camera_moves.yaml 里 enabled 的运镜——现在六种（L-192）：static 固定、push_in 推近、pull_out 拉远、幻想段的 bolt_push_settle、走动镜的 handheld_follow、pedestal_up 升；一镜里有 2 个以上的人在画时只写 static / push_in / pull_out / handheld_follow；横移 / 环绕 / 摇 / 俯仰 视频模型做不出，不要写。 [K-WRT-813]
- 每镜【下镜】写“切法｜落点动作”：同一场里相邻两镜切在动作中段（上一镜结尾留一个还在进行的动作，下一镜从这个动作的后半开始）或接视线落点；对白说完接听者反应时写“声音先行 0.3–0.5 秒”；硬切只在换段 / 换场用并写“理由=”。切法只用：动作匹配切 / 视线匹配切 / 声音匹配切 / 声音先行 N 秒 / 硬切 / 叠化 / 光闪匹配切（只用于现实↔幻想切换）。 [K-WRT-814]
- 竖屏 9:16 构图：单人镜把主体放在上三分之一（眼睛落在上方三分线附近），人物看向哪边就在哪边留出空间，下三分之一只放手 / 道具 / 前景，不放关键信息（会被字幕和界面挡住）；两人以上写前景 / 中景 / 背景三层，用前景物件做纵深；横向摇移在竖屏里容易晕，运镜优先推近。 [K-WRT-815]
- 每镜在【光学】写三项：焦段（全画幅等效 mm）｜T 光圈｜高度=机位高度（例：85mm｜T1.4｜高度=1.5m 眼平）。按景别取表：建立镜头 24–35mm T2.8–4，一场最多一个；双人 / 中景 40–50mm T2，人物前后错落；过肩 / 单人近景 / 中近景 65–85mm T1.4–2；特写 85–135mm T1.2–1.4；插入镜头 100mm 微距 T2。长焦 + 大光圈才有真正的焦外光斑和压缩感，不要整集用同一支镜头。 [K-WRT-816]
- 背景层要有远处的实景光源或器材（灯架、亮着的灯泡、霓虹、监视器、窗外的灯、反光板），它们在大光圈长焦下才会变成圆形光斑；不要把背景写成一片空白幕。 [K-WRT-817]
- 两人同框要前后错落（一人靠前、一人靠后，景深不同），身体斜 45° 对着对方，不要并排站成一排正对镜头——那是合影，不是电影。 [K-WRT-818]

- 现实段和幻想段之间切换时，前后两镜都要写出同一个触发画面：上一镜最后一拍以它收尾（例：女主 A抬眼看向关着的环形灯架，环形灯啪地亮起、暖白光闪满画面），【下镜】写“光闪匹配切｜…”；下一镜【衔接】写“承：光闪｜…”，img 和第一拍从它的余晖进（暖光晕开、前 0.3 秒略过曝）。只写“下巴抬起”这类动作，观众看不出换了段。 [K-WRT-L201b]

- 一集都在同一间影棚 / 房间时，不要每镜都对着同一面背景（“每一个 episode 里面的 scenes 都一样，S6 和 S1 一模一样”）。按机位方向把同一个空间分成几个背景视向，各登记一个子场景 id（<父场景id>_<视向>，例 sk_xxx_rev 反打侧 / sk_xxx_door 门口 / sk_xxx_mirror 化妆区 / sk_xxx_top 俯视），本集场景表各写一行，每镜【场景】写自己的视向、img 背景层照它写（反打看相机位那一侧的灯架 / 监视器 / 远处门，门口机位看带小窗的门和器材箱，高机位看地胶标记和桁架影子）。相邻两镜不同视向（过肩复刻对、光闪配对除外），正反打两镜相反视向，白幕正面最多占一半的镜。同一空间、同一套灯、同一条轴线，衔接仍写“同场换机位”。 [K-WRT-L203b]
- 每镜字段写全（img、场景、人物、衔接、站位、光线、镜头运动、分拍、motion、时长、sound、H3），分拍按秒切段一直写到镜长；镜1 用近景或中景；特写 / 近景 / 中景的 img 不写鞋、高跟、腿、脚（画面外的下半身）；有台词或 🎙 的镜分拍写清视线落点；每句台词之后，下一镜的分拍要写听者的反应（名字 + 视线 + 表情）；分拍不写穿上 / 脱下 / 披上 / 换上的过程（换装另起一镜、首帧已换好）；不写回头、看镜头；台词和独白不用“很生气 / 很难过”这类情绪直陈。 [K-WRT-H08]
- 描写外貌 / 动作 / 服装的每个分句都写人名主语（编译器按景别删句时，没主语的描写会归给别人）；特写只许一人露脸，另一人写背影 / 局部，要两人都露脸就写中景。 [K-WRT-H13]
- 两个人都要露脸的镜头用中景或更宽；要拍近景或特写时，只让一个人露脸，另一个人写成前景的肩、背影或手（人物行写“局部”，或在 img 里该人自己的小句写“只露肩 / 背影 / 被越过”——这样的过肩前景不算露脸）。 [K-WRT-H16]
- 集头里给本集每个场景写一行场景定稿：`**场景定稿｜<场景id>**：陈设=<1–5 件，照抄场景表>｜主光=<灯光方案名或动机光源（方位）>｜站位=<名>：<左/中/右>·<姿态>；…｜屏幕方向=<谁在哪侧、面朝哪边>`。各镜的人物左右、灯光都要和这一行一致；剧情里有人换位置，就在那一镜的衔接写“承：动作｜<名>移到<侧>”。过肩镜里前景的肩、背影（人物行写“局部”）也算占了画面那一侧，左右同样要和定稿行一致。 [K-WRT-H23]
- 同一场里换机位或接力的镜，衔接行写清上一镜交过来的是什么：视线（谁看向哪）、动作（手上正在做的事）或声音（哪一声响）——“承：视线｜女主 A看向门口”。不要写“承：环境”。 [K-WRT-H24]
- 同一场里不要每镜都重写一遍环境（例如每镜都写“落地窗外霓虹虚化成光斑”）。场景长什么样由场景定稿行交代；img 只写本镜的人物、动作、机位和这一镜独有的东西。人物扶、靠场景物件的接触分句照写。img 里 QW-W9 要求的光线句照写，但写成带人名的句子（“暖黄顶灯从上方落在女主 A的肩上”），不写成和前镜一样的纯环境句。 [K-WRT-H25]
- 在画角色的造型里有外层衣物（西装外套、风衣、大衣、开衫、披肩等）时，img 里写出这件外层的品名和状态（穿着 / 敞开 / 脱下搭在手臂上）；外层不写进 img，出图会把它丢掉。 [K-WRT-Q01]
- 人物行标“局部”的角色，img 只写入画的部位（手、背、肩），不写他的脸、五官、头发；脸或头发要入画，就在人物行写“在画”。 [K-WRT-Q02]
- 下装写具体品类和长度（铅笔裙、包臀裙、A字裙、百褶裙、直筒西裤、阔腿裤；及膝 / 过膝 / 短款），不写“西装裙 / 套裙 / 职业裙”这类泛称——出图会把“西装裙”画成西裤。 [K-WRT-Q05]
- 任何字段都不写演员看镜头——不写“看向镜头、直视镜头、对着镜头笑、视线越过镜头、看着观众”，H3 也不写 looks into the camera / at the lens / at the viewer。近景要“看向镜头一侧”时，写成看向画外具体的人（“看向画外左侧的男主 B”）。 [K-WRT-A02]
- 写人物朝向时，朝向画里的人或物（“四分之三侧脸朝向男主 B”“身体朝向窗边的灯”），不写“正面朝镜头 / 面向镜头 / 正对镜头 / 朝着镜头”——出图模型会把“正面朝镜头”画成直视镜头；H3 同样不写 facing the camera / toward the camera / front view。 [K-WRT-A06]
- img 是首帧的唯一来源，每个在画的人都写一句视线落点——看画里的谁或什么（“女主 A的视线落在男主 B的手上；男主 B垂眼看着文件”）；闭眼、背对写明即可；不写“看着前方 / 远处”。首帧里谁没写视线，出图就默认让他看镜头，视频会接着看镜头。落点在画外时，img 写方位 + 物（“视线投向画面右侧的门口”），不写画外角色的名字（人物行标画外的人不能出现在 img 和结束状态（motion 里 —— 之后那段），QW-CH4）；分拍 视线= 可以写“画外门口的男主 B”。 [K-WRT-A07]
- cast 写“局部（部位）”的人必须真的不露脸——景别写局部特写（只拍手 / 腰 / 腿）或背影，结束状态也不写他的嘴唇、视线、转身；要露脸就写“在画”（不露脸却出了脸，出图没有身份脸参考，就会画成陌生人）。两人以上在画的镜头不写倒影、映出、镜中（倒影会被画成多出来的真人），视线落点写实物。 [fb-0004 / ep07-S3] [K-WRT-212]
- 每一镜的 **场景** 行细节开头写 【幻想段】 或 【现实段】（例：**场景**：sk_xxx｜【幻想段】<场景里的一处>，<一盏灯亮起>），按这一镜对应的 P2 节拍 / P3 场景的段落标记写，没标的节拍跟上一拍。调色（幻想 C 黄金时刻 / 现实冷调）和运镜（bolt_push_settle 只在幻想段）都按这个标记走：漏标 = 整镜按现实段出，幻想段白写。 [REVIEW-B P1-2 / ep01 镜2 镜3] [K-WRT-213]

## 分拍与动作
- 分拍每拍写 视线=、表情=；双人镜每拍再写 反应=（另一人的眼睛 / 嘴 / 手 / 肩的可见变化）。 [K-WRT-I02]
- 一个连续动作需要拆成多镜时，用 **衔接**：接力 并把各镜时长写成相同；后一镜 H3 正文开头先复述上一镜结尾画面，新动作在 1.5–2 秒之后才开始。 [K-WRT-R07]
- 分拍每 2 秒至少一个看得见的变化（视线移向某物、表情变化、手部动作、转头、起身）；“保持 / 定住 / 凝固”不算变化——ep02 有 7/11 镜因为只写状态而成了静止画面。 [K-WRT-002]
- 对白镜在分拍里写清说话人看向哪里（看对方 / 看屏幕 / 低头），以及在画听者的一个反应动作；官方表格要求每句台词都有具体的视线和身体动作变化。 [K-WRT-003]
- motion 的结束状态写成“动作仍在进行中”的瞬间（例如正抬起手、正转过头），不要写成完全停住的姿势——v0 有 10/11 镜结尾定住。 [K-WRT-004]
- 只改表达、不加事实：结尾钩子用原稿已有的事来做，不在最后几秒加新消息、新时间（如“明晚八点”）、新人物入画、新痕迹或让睡着的人醒来；手机屏幕 / 纸面上不写原稿没有的文字；改台词时不要多加一层意思（如“签不签，我说了算”）；不要为了动作感新增道具交互（按按钮、勺子掉落溅汤、起身又坐回）；不要把后面才发生的事提前到镜1 当钩子；原稿写“两人对视”就保留对视，不改成看镜子里的自己。 [K-WRT-H06]
- 每镜都要发生点什么：有台词，或分拍里写一个看得见的变化动作（推门、抬手、手机亮起）；不写整镜“保持 / 静止 / 凝视”。 [K-WRT-N01]
- 转折放在全集中段（约 35%–75% 的时间位置）：让一个人入画，或让一件东西被看见 / 打开 / 亮起，用画面交代变化。 [K-WRT-N04]
- 每集结尾的悬念换着用：问句、揭示一件东西、动作中断、视线看向画外；相邻三集不要用同一种。 [K-WRT-N05]
- 整集只有一个人出镜的独角戏：要让外部压力进画面——对方以画外人物、手机消息、来电、门铃、敲门或屏幕文字出现（人物行写“<名>（画外）”）；压力出现之后，主角要做一个看得见的选择动作（扣下手机、删掉、拒接、拿起、推门离开…），不能只写凝视和停顿。 [K-WRT-H14]
- 首帧里每个在画人物都要写一个“人名主语 + 接触动作 + 场景里的物件”的分句——扶着门框、坐在桌沿、手里拿着杯子、肩靠在墙上、手撑在吧台上；身体写侧向或四分之三侧。不要写人物正面直立、居中、对着镜头的设定图姿势。 [K-WRT-H15]
- 每集都要让观众看见“这件事办砸了会失去什么”——具体的人、物、位置或关系（被收回的钥匙、要搬走的箱子、会被看见的名字），放进画面或台词里，不写抽象的担心。 [K-WRT-H17]
- 对手戏里要有一方想要的和主角相反，并且当面施压、拒绝或设条件；不能整集都是顺从、问候和配合。可以为此补情节节点，但谁、在哪、什么关系不变。 [K-WRT-H18]
- 末镜的最后 2 秒必须在画面里出现新东西：一个新动作、一件新物件被拿出 / 亮出，或新人入画；不要只靠独白里的疑问收尾，末镜也不要和前一镜是同一个画面。 [K-WRT-H19]
- 一镜只放一个主动作。不写转身、走向、走过这类走动——要换位置就切到下一镜，下一镜开头人已经在新位置；要表现起身或离开，只写镜尾的起势（重心前移、手撑桌沿）。新人进画写“入画”。 [K-WRT-H20]
- 台词不要直说意图。每集至少有一处，台词和同一镜的动作是相反的：嘴上说没事，手在攥紧；嘴上说走吧，脚没动。 [K-WRT-H21]
- 镜 1 的前 5 秒要让观众知道“谁遇到了什么事”：主角在画，并且有一件正在发生的事（手机亮起、门被敲响、有人递来东西），不是空镜或氛围。 [K-WRT-H22]
- 每镜分拍里至少有一拍写看得见的身体动作（抬手、转头、视线移向某物、胸口起伏、起身）；“保持 / 定住 / 静止 / 凝固”不算动作，整镜都这样写会出成静止画面。 [K-WRT-Q03]
- 衔接写“接力｜承：动作｜<动作>”时，本镜 img 或分拍第一拍要写出被承接的同一个动作或物件（例如上一镜“指尖停在耳侧”，本镜第一拍从指尖在耳侧开始）。 [K-WRT-Q06]
- 每一拍的 视线= 都写具体落点——画内的人（名字或部位，如“男主 B的手”）、物件（“汤碗边缘”），或画外有名有姓的声源；视线变化写成动作（“视线从手机移到他脸上”）。不写“看着前方 / 远处 / 虚空”，也不只写方向（“对面 / 画外 / 一旁 / 上方”要写成“对面的男配 C / 画外门口的男主 B”）；跨镜视线方向保持一致，翻转要写明。 [K-WRT-A01]
- 每一拍的 表情= 写看得见的面部动作（眉梢压低、眼睑垂下、嘴角牵起、下颌绷紧、呼吸一滞），用可演的动词，不写“情绪复杂 / 很激动 / 很有张力”；相邻拍的情绪连续变化、不跳；台词的语气（音高、语速、腔调）写在对白括号或 H3 的 <d> 外面。 [K-WRT-A04]
- 画面里有两个及以上在画的人时，每一拍除了主角，其他每个人都在 反应= 里写“名字：视线落点 + 表情”（例：反应=男主 B：视线落在她手上，下颌绷紧；三人时用“；”接着写下一个人）；H3 正文里每个在画的人各写一句，主语是这个人，写他看向谁 / 什么和脸上的变化（例：“He glances at her hand, his jaw tightening.”）。 [K-WRT-A05]
- 返修时只照“镜N：…”逐条执行系统给出的插入 / 删除 / 移动指令，未被点名的镜逐字不动；一镜最多一条 🎙；同一镜既有台词又有 🎙 时【配乐】写“对白避让，独白避让”。 [K-WRT-208]
- 镜面 / 玻璃场景（镜面墙、全身镜、落地窗）里手不碰反光面——不写“掌心贴上镜面”“手扶镜面墙”“指尖按在玻璃上”（生成模型会把真手和倒影画成粘连、倒影姿势跟不上）；手要落点就抵在自己身上或场景实物（锁骨、桌沿、扶手）；一镜 8 秒内手部动作合计不超过 2 处，其余节拍用视线、呼吸、肩线、表情给变化。 [fb-0001] [K-WRT-211]

## 时长与节奏
- 节奏按项目方要求“稍微快一点”：每拍至少一个完整的可见动作，H3 正文每秒约 18–25 个英文词，不写 slowly / at slow speed / gently 这类拖慢的词（需要慢镜头时在 **镜头运动** 行写 速度=慢）。 [K-EDT-I01]
- 穿外套或西装的人要从坐变站（或站变坐、起身离开）时，不要放在同一镜里做完：这一镜停在准备起身，下一镜从已经站好开始，衔接写“接力｜承：动作｜起身”。视频模型在一镜里做大幅动作时，外套会变形、变无袖甚至消失。 [K-WRT-704]
- 单镜时长建议 ≤6 秒（剪辑会把更长的拆成两刀）；远景 / 全身镜头 5–6 秒且尽量不说话（脸小时 H3 容易画崩）；>10 秒的镜头只能排一条长镜头道，最慢。 [K-WRT-005]
- 每集第 1 镜 ≤3–4 秒，或在前 3 秒内有明显动作 / 运镜（v0 前 3 秒无切点，第一句对白在 8 秒后）。 [K-WRT-006]
- 相邻镜头景别尽量交替（特写 / 近景 / 中景），连续同景别不超过 2 镜（v0 相邻同景别 8/10）。 [K-WRT-007]
- 镜1 写 4 秒左右，从动作中段的特写起手（手、眼、关键物件），3 秒内用视线或画外声把观众引到镜2。 [K-WRT-106]
- 整集成片要 ≥60 秒，但剪辑会收紧节奏、剪掉约 30%。所以写作时按剪后算：想要 60 秒成片，P4 各镜时长加起来要 ≥86 秒（60 ÷ 0.7）。不够就补镜（无台词过渡 / 反应 / 局部特写），不要拉长单镜。 [K-WRT-819]
- 镜头一开始动作就已经在进行——第一拍（0 秒起）写一个正在发生的动作（“她把杯子推过去”），不写先定住再开始；每拍 1.5–2.5 秒，一拍一个主动作，次要动作稍后跟上；不连着两拍写“保持 / 定住 / 一动不动”。对白镜一般 2–6 秒，晚进早出。 [K-WRT-A03]
- 返修时系统可能要求你“把镜N 改成 X 秒，并在后面插入一个 Y 秒的新镜”：台词和 🎙 逐字保留在镜N；新镜没有台词，承接镜N 的动作或给在画的人一个反应 / 局部特写，场景和人物沿用镜N；两镜的分拍、motion、H3 时间码都按新时长重写。 [K-WRT-T03]
- 单镜时长按需要写，不要为了凑总时长把每镜拉长：没有台词或独白的镜写 4–6 秒；有台词的镜，时长 ≈ 台词字数 ÷ 4.5 + 1.5 秒，最少 4 秒，一般不超过 6 秒。总时长不够时加镜（反应镜、局部特写、过渡镜），先把镜数写到上限，再考虑把台词镜放长。 [K-WRT-Q07]
- 分拍动作不要写对身上正穿着的衣服的整理动作（抚平外套下摆、拉衣角、收紧衣领等）——视频模型会把外套先脱掉再穿回。想表达整理 / 镇定，写不碰衣服的动作，例如手放回身侧、深吸一口气、肩膀放松。情节本身就是穿脱衣物的，单独成一镜。 [K-WRT-702]
- 先定镜数，再按输入给的“镜数 → 平均每镜秒数”表分配 **时长**（镜1 约 4 秒；总时长不够时先加镜，单镜按台词需要写，见 K-WRT-Q07），各镜相加必须落在输入给的区间。 [K-WRT-203]
- 改某一镜的 **时长** 时，同一镜的 **分拍** 必须续写到新镜长（最后一拍的止 = 新镜长），H3 正文的分拍时间、Picture 2 对齐秒数、**台词时段** 一起按新镜长改。 [K-WRT-204]

## 身份锚点
- 锚点句（第一句）逐字包含每个在画角色的人物表 EN外貌短语（含族裔、年龄、发型）；说话人第一次开口的那句逐字包含其 VOICE 短语，VOICE 必须写明 Mandarin。 [K-PRM-010]
- 人物表每个造型的服装字段须逐项写品类、颜色、材质（上衣 / 下装 / 鞋 / 配饰），按集按造型分别给；笼统词如「休闲装」系统无法渲染成确定造型。 [K-WRT-R03]
- 每个角色给 3 个不可变视觉锚点（脸部 / 着装 / 道具各一），写具体可见的形状、位置、颜色，不用模糊形容词；角色在画的每镜都原样带上。 [K-WRT-R05]
- 每个在画角色在人物表里都要有 EN外貌短语（族裔、年龄、发型、脸型），每个开口角色都要有 VOICE（含 Mandarin、音色、音区）；新角色第一次出场前先登记。 [K-WRT-009]
- 各集 logline 里出现的每个人都必须在人物表里（有 EN 外貌短语、VOICE、固定造型）；不想加进人物表的人写成画外 / 不露脸、不点名。 [K-WRT-201]
- 每个 **造型｜<角色>** 行从输入给的登记造型里选一套，服装 / 鞋 / 饰品和 EN 逐字照抄；全剧不另起新造型（规模化：一套造型一张设定图，跨集复用）。 [K-WRT-202]
- 全部角色是 22 岁以上的成年人；外貌、动作、服装描述不写任何儿童化 / 未成年化的词（学生、校服、幼态、teen、child、schoolgirl 之类）；亲密内容只发生在成年人之间、出于自愿。 [K-WRT-205]
- H3 锚点句、说话人第一次开口的句子、画外说话人，都逐字照抄输入【系统预拼片段】里的对应片段（含开头的 a，不改成 one / the；VOICE 不意译）；画外 / 局部的角色在 H3 正文里不写 EN 外貌短语；一镜最多一条 🎙。 [K-WRT-206]
- 剧情不改变已锁定角色的外貌锚点：不改发色、不剪发、不换发型、不改标志物（标志物以全局头角色锁为准）；需要“为他改变”的情节点，换成不改变外貌的等效动作。 [K-WRT-207]
- 锚点句里每个在画角色写一次“<外貌短语> in <本镜造型 EN>”，造型 EN 与本镜生效的造型行一致；合并 / 拆镜后镜号顺延时，造型切换行“镜N起”的镜号一起改。 [K-WRT-209]

## H3 正文
- H3 正文从第二拍起，每拍以 `At 00:SS.mmm,` 开头（时间 = 该拍起点，严格递增，每 1.5–2 秒一拍，写到镜尾）。 [K-PRM-I01]
- 照旧写 FL2VA 四块；“… settles into … established by Picture 2 at the end of the shot.” 单独成一个子句，前面的动作句写完整（系统只给首帧时会删掉这个子句，其余一字不改）。 [K-PRM-001]
- 画面里真实可见的文字（招牌、屏幕字、霓虹）在 H3 正文里用英文双引号原样写一次；没有可见文字就别写引号。 [K-PRM-006]
- H3 正文只写画面里有什么，不写 Avoid / no / without 清单（模型 cfg=1，否定词会把被否定的东西画出来）。 [K-PRM-007]
- H3 正文写“从首帧开始发生了什么”：至少 2 个看得见的身体动作或表情变化，按时间顺序；需要快时直接写力度（sharply、at fast speed），不要只写 maintain / remain 之类的保持状态。 [K-PRM-009]
- H3 正文不写人名和触发词（全局头触发词表里的词）；每镜一个官方运镜，写成句中动作（The camera pushes in with small amplitude at slow speed as …）。 [K-PRM-012]
- H3 英文正文须自含本镜人物姿态、可见服装和主光源；只写在中文 img 字段的画面信息在参考生视频模式下不会生效。 [K-WRT-R02]
- H3 运镜写成一句动作：The camera pushes in with small amplitude as …；一镜只用一种运镜（不叠推 + 摇 + 跟），中等幅度、正常速度不写，需要快写 at fast speed。 [K-PRM-101]
- 拉焦写成看得见的变化（the reflection blurs as her face sharpens in the foreground）；主观视角写成机位位置（from behind her shoulder …），不写 focus pull / POV。 [K-PRM-102]
- 第一句写清景别、机位、谁在画面哪一侧、光从哪来——纯 Ref2VA 没有首帧，构图全靠这一句。 [K-PRM-103]
- 画面里有两个及以上在画的人时，每一拍除了主角，其他每个人都在 反应= 里写“名字：视线落点 + 表情”（例：反应=男主 B：视线落在她手上，下颌绷紧；三人时用“；”接着写下一个人）；H3 正文里每个在画的人各写一句，主语是这个人，写他看向谁 / 什么和脸上的变化（例：“He glances at her hand, his jaw tightening.”）。 [K-WRT-A05]
- H3 正文第一个时间码（At 00:0x）之前，写出开场那一刻每个在画的人眼睛落在哪里（例：her eyes resting on the bowl in her hands; his gaze fixed on her hand）；单人镜正文里也至少写一处视线。只写正向落点，不写 not looking at the camera（H3 不认否定）。 [K-WRT-A08]

## 声音
- 每镜【配乐】都写“强度 0–3”；一集里强度至少有两档，情绪最高的那一镜写 3——剪辑节奏和配乐起伏都按这个数走。 [K-WRT-803]
- 【H3 audio】和 overall_soundscape 每镜必写 1–4 句英文，即使安静也写出环境底噪（空调声、远处车流等），不写 N/A。 [K-PRM-002]
- 每句台词（**对白** 与 <d> 内）以句末标点结尾（。！？…），否则 H3 开头容易出乱语。 [K-PRM-003]
- 同一镜里在画但不说话的人，在 H3 正文里写他 / 她 silently 做什么（例：listens silently），不给编号。 [K-PRM-004]
- 画外台词写成 `(S1) says in an off-screen voiceover: <d>[Chinese] …</d> while her lips remain completely closed.`（他用 his），不再单独另起一句。 [K-PRM-005]
- non_diegetic_music 只写乐器、速度、节奏、强弱变化；不写 “providing a … background layer”、restrained、atmosphere 这类解释作用或情绪的词。 [K-PRM-008]
- 只有 🎙 独白、没有台词的镜头，说话人在画时嘴是闭着的：分拍和 motion 不写开口、张嘴、说话、嘴唇动，**嘴型** 写 <角色名>=闭合。 [K-WRT-Q04]
- 每一拍的 表情= 写看得见的面部动作（眉梢压低、眼睑垂下、嘴角牵起、下颌绷紧、呼吸一滞），用可演的动词，不写“情绪复杂 / 很激动 / 很有张力”；相邻拍的情绪连续变化、不跳；台词的语气（音高、语速、腔调）写在对白括号或 H3 的 <d> 外面。 [K-WRT-A04]
