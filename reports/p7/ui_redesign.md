## 旧版（60 分）主要问题
- 总览是表格，**一张图都没有**（违反“总览以图为主”）；状态是英文代码（ready / best_effort / need_frames…）。
- 要你做什么不清楚：没有“要你处理”的汇总；原因是长串原文。
- 审片页只有键值表 + 一排按钮；修改 / 驳回用浏览器 prompt；看不到历次版本、看不到剧本。
- 尽力版自动用后，页面显示的是“最近一次出图”，不是“当前版”（ep05-S1：最近 #3 是坏图，当前是 #2）——**数据口径错**。

## 现在
- **总览**：顶栏五阶段进度（剧本 / 首帧 / 尾帧 / 视频定稿 / 成片）+ 实时灯；“要你处理”横幅（一句话说现在要不要你管 + 预计出完时间 + 尽力版数）+ 一键全部用这版；按集 / 按状态芯片（带数量、有待办的集带蓝点）；每集：阶段、耗时对目标 50 分钟与主因、成片卡（可直接播放）、彩色进度条、胶片条（点了跳到那一镜）；每镜一行三格大图（点开看大图 / 播放，←→ 翻）、出片进度环、剧本一句 + 台词、原因（点开展开）、“用这版 / 看片 · 修改 / 去触发”。
- **审片**：三大格（首帧 / 尾帧 / 视频播放器）+ 没过的项变成大白话标签（G1 看镜头 / 排排站、Q1 脸不像本人…）；底部决定条“✓ 用这版 / ✎ 修改 / 更多”；修改面板（选首帧 / 尾帧 / 视频 + 写意见）；右栏：剧本 / 版本（历次出图缩略图，当前版、尽力版、过没过）/ 任务记录 / 状态明细；上一镜 / 下一镜（本集第几镜）；`#tab=versions` 深链；←→ / E 快捷键。
- **公共**：浏览器弹窗（confirm / prompt）全部换成页面内弹层（说清楚会发生什么）；密钥一个小牌（已登录 / 粘密钥，点了可清除），写操作没密钥会弹层粘一次；提示条；深色 / 浅色；手机宽度不横向滚动。
- **当前版口径修正**：有尽力版的镜按 takes.json `active` 显示真正的当前版（文件口读，缓存 60 秒），审片页注明“最近一次出的是第 N 版（没被选为当前）”。
- 功能一个没删（项目方规矩“UI 改版不删功能”）：定稿、驳回、撤销定稿、取消排队、重出 / 按意见改、拼成片 / 强制重出、成人镜触发 / 撤销、清除密钥、一键（全部 / 本集 / 单镜）、剧集切换、刷新、轮询、过期 / 全局过期 / 缺失 / 候选 / 备注全保留。
