# P0：批量定稿 N7 / N8 + 显式成人检查（审查 3 §3）

## 改了什么
- **N7**：`db.review_bulk` 遇到已 `rejected` 的镜：
  - 跳过，并在返回的 `rejected` 里列出原驳回原因。
  - 只有调用方把这一镜逐镜列进 `confirm_rejected`（`BulkReviewReq` 新字段）才改成“用这版”，reason 记“覆盖了之前的驳回（逐镜确认）”，事件里也记一笔。
  - 总览页的一键候选（`app.js usable()`）本来就不含已驳回的镜。
- **显式成人检查**：`review_bulk(adult_of=is_adult)`：剧本判为成人且未触发的镜，就算视频行是 done 也不批量定稿。触发过的可以。
- **N8**：审片页新增“撤销定稿”按钮（`PUT /review state=unreviewed`，服务端原来就收）。确认文案改成“单镜点进去点‘撤销定稿’或‘驳回’”，不再承诺不存在的“修改”按钮。
