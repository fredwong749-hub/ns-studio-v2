## 改了什么（对应审查编号）
- **B1**：`ns2/auth.py` 共享密钥头 X-NS2-Key。API：非 GET + 全部 /api/worker/* 要密钥（读不到密钥 = 写全拒）；只读 GET 开放给浏览器。
  `/files` 只给图 / 片 / JSON（M12：不外泄 queue.db / 密钥）；worker 文件口 :8901 全部要密钥。`Enq` 拒自带 `key`、拒 `state=running`；
  `PUT /api/runs` status 白名单；`Fin.state` API 层校验。API 实际启动 `--host 10.0.0.33`（审查读到的 0.0.0.0 是 docstring，已改）。
- **B2**：`api.is_adult()` 按导入稿每镜 `adult`（旧 classify_adult 口径；读不到剧本 / 剧本里没有 = 当成人，fail-closed）；
  `db.enqueue(adult=…)` 强制 owner_trigger=1（调用方只能加严）；新 `triggers` 表 + `POST /api/shots/{id}/trigger`；
  定稿 passed **不再**顺带放行（定稿 ≠ 触发）；requeue 回队的成人行重新挡住。worker 第二道：视频步 `shot_adult` 未触发直接 blocked、不提交 ComfyUI；
  帧步交给旧 FrameExec 成人闸（只在 payload.owner_triggered 时认新系统的触发）。
- **B4**：`enqueue_video.KEEP` 加 reason / missing / ref_slots；blocked 文案带编译器 reason 原文。
- **B3（部分）**：视频 take 的 op_id 绑这一次渲染 `ns2-{job}-r{第几条}-{变体}-s{种子}`；重放时按 attempt 找回已写那条（不再 KeyError 死循环）；
  重打分 op_id 每次唯一；`wait` 超时 / HTTP 错 → `cancel()`（/queue delete + 是我们的才 /interrupt）。
- **M4**：ComfyUI 出错 / 超时 / 没产出 / 连不上统一 infra（不烧变体机会）；HTTPError 立即返回；连不上 300 s 宽限。
- **M5（部分）**：上传缓存键带 mtime+size；Comfy 侧文件名加随机前缀；拷贝 3 次重试 + 临时名改名。
- **M13（部分）**：requeue 判 rowcount（没改到 → 409）、清 result / beat_at、infra 连续计数在 requeue 后重算。
